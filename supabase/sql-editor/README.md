# Schema im Supabase SQL-Editor einspielen

Die Dateien hier sind `supabase/schema.sql`, aufgeteilt in kleine Teile.
Der Reihe nach ausführen (01 → 07), jeweils:

1. Im Supabase SQL-Editor **New query**
2. Datei auf GitHub öffnen → **Copy raw file** (Kopier-Symbol) → einfügen
3. **Run** (Warnungen zu „destructive operations“ bestätigen)

Alle Teile dürfen wiederholt ausgeführt werden.
